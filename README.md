# The Builder Studio - Business Portfolio Website

## Project Overview

Build a world-class premium business portfolio website for **The Builder Studio**.

This is NOT a freelancer portfolio.
This is NOT a software agency website.
This is NOT a startup landing page.

The Builder Studio is a **Product Studio / Venture Builder** that helps founders transform raw ideas into profitable startups.

Our positioning:

> "We are not freelancers.
> We are not agency owners.
> We are builders."

We partner with founders, validate ideas, engineer products, launch MVPs, and help them reach market faster.

The website should instantly communicate:

1. Who we are
2. What we build
3. How we help founders
4. Our proof of work
5. Why founders should trust us
6. How to start working with us

---

# Design Direction

## Visual Identity

Style:

* Modern
* Premium
* Futuristic
* Minimal
* Founder-focused
* Apple + Linear + Vercel inspired
* Smooth luxury UI

Color Palette:

Primary:

* Black (#000000)

Secondary:

* White (#FFFFFF)

Accent:

* Soft grayscale gradients
* Glass effects
* Subtle silver highlights

Avoid:

* Bright colors
* Cheap startup colors
* Agency-style designs
* Cartoon illustrations

Goal:

The site should feel like:

"If a startup founder had $1M and wanted a serious product partner."
