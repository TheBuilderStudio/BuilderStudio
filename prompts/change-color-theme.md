# The Builder Studio — Complete Design System Update

IMPORTANT:

Do NOT redesign the website from scratch.

The website structure, sections, content hierarchy, and business messaging are already implemented.

Your task is to update the entire visual design system, color system, spacing, typography, backgrounds, animations, and component styling according to the new brand direction shown in the reference image.

---

## New Brand Direction

The Builder Studio is NOT a startup.
The Builder Studio is NOT a software agency.
The Builder Studio is NOT a freelancer portfolio.

It is a premium Venture Builder / Product Studio.

The visual experience should feel:

* Premium
* Sophisticated
* Futuristic
* Founder-focused
* High-end
* Calm
* Confident

Avoid:

* Bright startup colors
* Neon cyberpunk look
* Excessive glow effects
* Heavy gradients
* Agency-style illustrations
* SaaS template appearance

Accent Usage Rules:

* Active states
* CTA highlights

# Background Design System

The current reference image represents the new direction.

The entire website should follow the same visual language.

Create layered backgrounds using:

1. Black gradients
2. Dark charcoal gradients
3. Very subtle grid overlays
4. Soft radial gradients
5. Smooth curved lines
6. Atmospheric depth

The website should feel like:

A premium digital studio floating in a dark space.

Avoid:

* Rooms
* 3D objects
* Cubes
* Floating cards everywhere
* Sci-fi environments

The depth should come from gradients and lighting.

Not from objects.
